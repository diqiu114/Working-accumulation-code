## 搭建sftpgo在ubuntu24

1. 从https://github.com/drakkan/sftpgo/releases/页面下载指定cpu架构的.tar.xz，解压：

   ```
   mkdir sftpgo
   tar -xvf sftpgo_v2.7.1_linux_arm64.tar.xz -C sftpgo
   ```

   运行

   ```
   cd sftpgo/
   ./sftpgo serve
   ```

2. 网页登录

   ```
   http://192.168.100.121:8080/web/admin/login
   http://192.168.100.121:8080/web/client/login
   ```

   



## 2.7.1版本支持中文：

1. sftpgo.json中添加

   ```
   "languages": [
   	"en", "zh"
   ],
   ```

2. templates/common/base.html文件中添加

   ```
   const lngs = {};
   //{{- range .Languages}}
   //{{- if eq . "en"}}
   lngs.en = { nativeName: 'English' };
   //{{- else if eq . "it" }}
   lngs.it = { nativeName: 'Italiano' };
   //{{- else if eq . "de" }}
   lngs.de = { nativeName: 'Deutsch' };
   //{{- else if eq . "fr" }}
   lngs.fr = { nativeName: 'Français' };
   //{{- else if eq . "zh" }}
   lngs.zh = { nativeName: '中文' };
   ```
